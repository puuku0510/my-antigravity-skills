# my-antigravity-skills

Antigravity（ノーチ）の動画制作・スライド作成用Skill集。

このリポジトリは、動画の素材収集やスライド・グラフの自動生成を効率化するための2つのSkillsをまとめたものです。

---

## 収録Skill一覧

### 1. [slide-source-collector](./slide-source-collector/)
* **概要**: YouTubeなどの動画台本から、関連するWebサイト、ニュース記事、X（Twitter）の投稿、書籍の表紙などのスクリーンショットを自動的に収集・整理する素材収集Skill。
* **特徴**:
  * 16:9スライドにそのまま貼り付けられるよう、余計なバナーを除去し、情報の見切れがない最適なフレーミングで撮影します。
  * Tier 1（グラフ・データ・X投稿：50%）、Tier 2（ニュース記事：30%）、Tier 3（Wikipedia・場所・ブランド：20%）のソース配分比率（50-30-20ルール）を適用し、視覚的な情報密度を担保します。

### 2. [pptx-skill](./pptx-skill/)
* **概要**: 台本（CSV、Googleスプレッドシート、Markdown）からPptxGenJSを使用し、Googleスライド互換のPPTXファイルを一発で自動生成するSkill。
* **特徴**:
  * 11種類（十数通り）の高度なスライドレイアウトテンプレートを内蔵。
  * `chart`（棒・折れ線・円グラフ）、`table`（色分け比較表）、`pyramid`（三角形の積層レベル図）、`formula`（シミュレーション数式）、`timeline`（横型タイムライン）などのグラフや図解をプログラムで美しく描画します。
  * パターン1（図解特化・赤ベース白背景）とパターン2（キャラ系テロップ吹き出しコラージュ）の2通りのデザインに自動対応。
