# my-antigravity-skills (配布用汎用Skillsパッケージ)

このリポジトリは、AI（Antigravity/ノーチ）を活用して**「X（Twitter）の高品質なスクリーンショット収集」**および**「PowerPointによるビジネススライド・グラフの全自動生成」**を効率的に行うための、スクール配布用の汎用Skill集です。

生徒の皆様が自分自身の発信やビジネスの資料作成で即座に導入・活用できるよう、個人情報やチャンネル固有の設定を完全に排除し、クリーンで汎用的な機能に特化して再構築されています。

---

## 📂 パッケージ構成

リポジトリ内は以下の2つの特化型Skillフォルダに分かれています。

### 1. [x-screenshot-collector](./x-screenshot-collector/)
* **概要**: X（旧Twitter）の投稿URLリストから、対象ツイートのスクリーンショット（本文＋投稿者＋日時が綺麗に入った画像）を自動収集するSkill。
* **特徴**:
  * ニュースや一般的なWebサイトは対象外とし、**Xのスクショ収集のみに100%特化**。
  * ヘッドレスブラウザの負荷による「PCのフリーズ」を防ぐため、**1回で同時に作業するのは最大2枚まで**とする安全バッチルールを内蔵。
  * 保存先はカレントディレクトリ直下の `./output/x-screenshots/`（相対パス）に自動で汎用化されています。

### 2. [pptx-chart-generator](./pptx-chart-generator/)
* **概要**: 数値データやMarkdown原稿（JSON）を元に、PptxGenJS を介してGoogleスライド互換のPowerPointファイル（.pptx）を全自動生成するSkill。
* **特徴**:
  * 特定のチャンネルカラーや固有ロゴマークなどのプライベート情報を完全に排除。
  * 誰でもビジネスで即戦力として使える**「ビジネスブルー」「 Slateネイビー」**などのプレミアムな汎用カラーシステムへ移行。
  * **48種類もの多様なスライド自動生成レイアウト**を同梱。円グラフ（ドーナツ）、折れ線グラフ、KPI大数字、ファンネル図、2x2マトリクス分類、ステップフロー、Before/After比較表、タイムライン、ピラミッド図などをがっちりプログラムで描画します。

## 🚀 導入と実行方法（生徒向け）

各フォルダ内の `SKILL.md` に詳細な仕様が書かれていますが、以下の手順ですぐに動作確認が可能です。

### pptx-chart-generator (グラフ・図解自動生成) の確認手順

1. **`pptx-chart-generator` ディレクトリに移動します:**
   ```bash
   cd pptx-chart-generator
   ```

2. **依存パッケージ（PptxGenJS）をインストールします:**
   ```bash
   npm install
   ```

3. **サンプルデッキの自動生成プログラムを実行します:**
   ```bash
   node sample-deck.js
   ```

4. **出力の確認:**
   * 実行に成功すると、`pptx-chart-generator/output/sample-deck.pptx` が自動で書き出されます。
   * 生成されたファイルをPowerPointで開くか、GoogleドライブにアップロードしてGoogleスライドでご確認いただけます。
