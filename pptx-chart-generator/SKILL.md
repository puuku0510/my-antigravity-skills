# PowerPoint グラフ・図解自動生成スキル

このSkillは、スライドの原稿テキストや数値データ（CSV、JSON、スプレッドシート、Markdown等）を入力とし、プログラム（PptxGenJS）を介して**プレミアムなビジネススライドデッキを自動生成**します。

---

## 🎨 プレミアム・ビジネスデザイン原則

このSkillで出力されるスライドは、すべて以下のプレミアムデザイン仕様に準拠しています。

1. **アスペクト比 16:9 厳守**
   * CSS/HTMLで描画する場合は `aspect-ratio: 16 / 9`（1280px × 720px）で固定。
2. **カラーシステム（ビジネスブルー）**
   * **プライマリ背景/文字**: Slate `#0F172A` (深みのあるダークネイビー)
   * **メイン強調**: Royal Blue `#2563EB` (清潔感と信頼感のある青)
   * **アクセント強調**: Orange `#F97316` (注意を引く差し色のオレンジ)
   * **ポジティブ/成功値**: Emerald `#10B981` (クリーンな緑)
3. **タイポグラフィ**
   * 見出し・本文にはレスポンシブな Google Fonts の `Noto Sans JP` を使用。
   * 英数字や強調数値には `Roboto` を適用。
4. **可読性の最大化**
   * 1つのスライドに情報を詰め込みすぎない（1スライド ＝ 1メッセージ）。
   * 箇条書きは最大5項目まで、文字のはみ出しがないように余白を十分に確保。

## 📊 利用可能な11種類の主要レイアウト

この自動生成エンジンは、以下の豊富なビジネス特化図解・グラフのレイアウトパターン（スライドタイプ）を標準でサポートしています。

| レイアウト名 | 映える用途 | 必須データ構成 |
|:---|:---|:---|
| **`kpi-three-col`** | 主要な指標・財務数値をアピール | 3つの数値 ＋ 補足ラベル |
| **`doughnut-three-col`**| 構成比率や市場シェアの3列比較 | 各項目名 ＋ 数値（％や割合） |
| **`two-col-text-chart`**| 課題解説 ＋ グラフの補足対比 | 解説テキスト ＋ 円/棒グラフデータ |
| **`step-flow`** | 進行ステップ、ロードマップ | 3〜6段階のステップ名 ＋ 説明 ＋ 期間 |
| **`comparison-table`**| 導入効果のBefore/After比較 | 各カテゴリ名 ＋ 現状 ＋ 改善後 |
| **`timeline`** | 歴史、経緯、中長期プロセス | 各年・日付 ＋ 見出し ＋ 補足説明 |
| **`quote`** | 名言、メッセージ、ビジョン | メッセージ本文 ＋ 発言者名 ＋ 役職 |
| **`before-after-split`**| 課題と解決の左右2分割カード | 課題ポイントリスト ＋ 解決策リスト |
| **`three-column`** | 3つの原則、3大メリット解説 | 3つの見出し ＋ それぞれの詳細説明 |
| **`funnel`** | コンバージョン、離脱分析 | 認知から購入までの各段階の数値・比率 |
| **`matrix`** | 2軸による4象限分類ポジショニング| X軸/Y軸の定義 ＋ 4箇所の象限名 |
| **`pyramid`** | 階層、レベル、ステップ積層 | 各レベル（Lv1〜Lv3）の定義テキスト |
| **`line-chart`** | 売上高や成長率の時系列推移 | 時系列ラベル（1Q〜4Qなど） ＋ 数値 |

## 🛠️ 制作手順（ワークフロー）

### STEP 1: インプットデータの受領と整理
ユーザーから原稿データ（Markdownテキストやスプレッドシート等）を受け取ります。

### STEP 2: スライド構成案の作成・提示
原稿から情報を分割し、どのスライドにどの「レイアウト名（上記11種）」を適用するかの構成案を提示します。

```markdown
構成案（全6枚）：
#01 [cover] 表紙スライド
#02 [kpi-three-col] 売上実績と顧客満足度
#03 [step-flow] 導入までの5ステップ
#04 [matrix] 市場競合ポジショニング
#05 [line-chart] 半期ごとの成長推移
#06 [ending] ご清聴ありがとうございました
```

### STEP 3: レンダリング実行
構成案に合意が得られたら、プログラム（`render-engine.js`）に定義JSON（`deckDef`）を渡し、一括でPPTXを自動生成します。

* **出力コマンド**: `node sample-deck.js`
* **出力ファイルパス**: `./output/sample-deck.pptx`
